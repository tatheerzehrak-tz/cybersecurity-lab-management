* **Project Description** This C program serves as a laboratory information management prototype for a university cybersecurity lab. It collects hardware, software, and tool inventory data, processes cost estimations, and displays a structured financial investment report.
* **Input:** Lab Name, Computers Count , Network Devices Count ,Security Tools Count ,Cost per Computer, Cost per Network Device, Software Cost
*  **Processing:** Total Computer Cost = Number of Computers x Cost per Computer     Total Network Cost = Number of Network Devices x Cost per Device     Total Lab Investment = Total Computer Cost + Total Network Cost + Software Cost
*  **How to Compile and Run:** GCC (GNU Compiler Collection) or any standard C compiler.
